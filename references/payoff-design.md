# 分集价值点与爽点节奏

## 核心原则

每集都要让观众有所得，但不要求每集都出现传统意义上的爽点。

本集价值可以是：

- **爽点**：反转、能力兑现、身份揭示、正义或利益回收。
- **泪点**：真相、牺牲、理解、遗憾或情感释放。
- **甜点**：信任、保护、关系确认或亲密升级。
- **惊点**：有效反转、世界规则揭示或认知颠覆。
- **笑点**：符合人物性格和情境的喜剧释放。
- **信息点**：改变观众理解、角色选择或后续局势的关键事实。

只有重复争吵、单纯受辱、谜团加深、突然昏倒、门外有人等内容，不能独立构成本集价值点。

## 节奏窗口

使用滑动窗口控制整体爽感，不做机械的每集打卡：

1. **每集一个价值点**：每集必须产生信息、关系、情绪或局势变化。
2. **三集爽点窗口**：任意连续三集至少有一次明确爽点。
3. **六集强兑现窗口**：任意连续六集至少有一次强兑现或阶段高潮。
4. **蓄势限制**：允许蓄势集，但不能连续两集都只有铺垫。
5. **类型轮换**：相邻明确爽点尽量不要重复同一类型；重复时必须提升代价、信息量或结果规模。

## 明确爽点判断

一个明确爽点至少包含：

1. **铺垫**：建立期待、压迫、误解、欠缺或目标。
2. **触发**：角色行动或关键事实进入场面。
3. **兑现**：发生可观察的结果，局势、关系、身份、利益或认知产生变化。
4. **情绪收益**：观众获得解气、惊喜、认同、成就感或压抑后的释放。

集尾钩子不能代替爽点。爽点负责完成本集回报，钩子负责制造下一集期待。

## 节奏等级

- **蓄势**：本集有信息、情感或人物价值，但没有明确爽点。
- **小兑现**：完成一个清晰的小回报或局部反转。
- **强兑现**：回收连续数集的压抑、误解或目标。
- **阶段高潮**：回收多条铺垫，改变主要关系或主线局势。

## 标注合同

在 `07_manuscript.md` 中，每集必须按“集标题 → 创作标注 → 正文”的顺序组织：

```markdown

- 钩子强度：强钩子 / 中钩子 / 基础钩子
- 目标时长：<第一集填写已确认的 1-5 分钟；其后填写 1 分钟>

- 钩子本集推进：

- 开头质量评分：
```

该标注放在开头，便于先审查本集剧情目标、价值点、兑现和钩子，再决定是否修改正文。它不属于小说正文；导出最终 Word 阅读稿时删除整个标注块和“本集正文”子标题，仅保留集标题与小说正文。

开头钩子与本集爽点不是同一个字段：钩子负责留住观众，价值点负责让本集有回报，集尾钩子负责推动续看。第一集开头质量评分至少 9/10，第 2-3 集至少 8/10，其后至少 7/10。评分依据为即时性、清晰度、异常度、主线关联和追看欲，每项 0-2 分。
