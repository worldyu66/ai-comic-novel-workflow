# 人物与场景确认提示词

这些提示词属于小说创作包，用于确认人物外貌、服装和主要场景构图，不用于生成图片或视频。

## 人物提示词格式

每个主要人物生成一份基础提示词；只有剧情确有需要时，才增加正装、工作装、情绪状态或年代变化等版本。所有版本必须保持人物身份锚点一致。

```markdown
## 人物：<姓名>｜身份：<剧情身份>

**身份锚点：** 年龄感、脸型、发型、身形、无品牌特征的服装细节、固定配饰
**外貌确认提示词：** <中文视觉描述>
**状态变化提示词：** <仅在剧情确有需要时填写>
**连续性说明：** <必须保持不变的外貌与服装特征>
```

## 场景提示词格式

为建立世界规则、改变人物关系、揭示线索、兑现主要爽点或决定结局的场景生成文字确认稿，不要机械地覆盖每一集。

```markdown
## 场景：<场景名称>｜对应集数：<N>

**剧情作用：** ...
**人物与连续性：** ...
**场景确认提示词（16:9）：** <包含主体、动作、地点、构图、景别、光线、情绪和连续性的中文描述>
**人物连续性：** <沿用哪些既定外貌，允许哪些变化>
```

## 视觉方向

以用户提供的视觉参考为最高依据。如果没有参考，先提出一套简洁统一的视觉方向，再编写确认提示词。不要混用无关画风、没有剧情依据的服装或不同画幅比例。
