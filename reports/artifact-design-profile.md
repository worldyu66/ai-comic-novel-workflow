# Artifact Design Profile

- Topic analysis: compact comparison list, no unnecessary plot detail before selection.
- Story bible: structured reference document optimized for continuity lookup.
- Outline: episode-level table with target runtime, purpose, and payoff visible at a glance.
- Manuscript: readable episode hierarchy with duration, summary, and diagnostic cumulative count after each episode.
- Visual-confirmation prompts: one repeatable template per character or key scene, designed for reviewing appearance and composition.
- Risk review: concise issue table with an actionable revision direction and resolution status.
