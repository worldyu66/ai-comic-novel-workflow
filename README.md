# AI 漫剧小说工作流 Skill

这是一个面向 Codex 的中文 AI 漫剧小说创作 Skill。它把素材分析、原创选题、故事设定、大纲强化、分集正文、内容风险检查和人物/场景确认提示词组织成一套可重复执行的工作流。

## 主要能力

- 从用户提供的小说、故事、笔记或大纲中提取可复用的受众需求和叙事机制
- 提供 5-8 个原创选题，并等待用户选择后继续
- 建立故事圣经、核心大纲和强化大纲
- 由用户确认大概目标集数和第一集时长，不设置固定总字数
- 为每集设计独立的开头留存钩子、观众价值点和爽点节奏
- 按 2-3 集一批自动推进，并维护进度、伏笔、关系和累计字数
- 检查正文中的意外英文、分集字段缺失和爽点节奏问题
- 输出主要人物和关键场景的 16:9 视觉确认提示词
- 最终导出干净的 Word 阅读稿，移除创作过程标注

## 创作原则

本 Skill 只提取素材中的题材需求、情绪机制和叙事结构，不复制原素材具有辨识度的角色、情节顺序、段落或对白。

开头钩子、本集价值点、明确爽点和集尾钩子是四个不同任务：

- 开头钩子负责让观众进入本集
- 本集价值点保证观众看完有所获得
- 明确爽点负责阶段性的情绪释放
- 集尾钩子负责推动观看下一集

第一集执行最强开头标准，前 3 集维持高留存，后续集数轮换钩子类型，避免连续使用同一种刺激。

## 安装

### 让 Codex 安装

在新电脑的 Codex 中发送：

```text
安装这个 Skill：
https://github.com/worldyu66/ai-comic-novel-workflow
```

如果仓库仍为私有状态，需要先在新电脑登录拥有访问权限的 GitHub 账号：

```powershell
gh auth login
```

私有仓库的其他使用者还需要由仓库所有者添加为协作者。

### 使用 Git 安装

Windows PowerShell：

```powershell
git clone https://github.com/worldyu66/ai-comic-novel-workflow.git "$HOME\.codex\skills\ai-comic-novel-workflow"
```

macOS 或 Linux：

```bash
git clone https://github.com/worldyu66/ai-comic-novel-workflow.git "$HOME/.codex/skills/ai-comic-novel-workflow"
```

安装完成后，在下一轮 Codex 对话中即可使用。

## 使用示例

上传或粘贴参考素材，然后发送：

```text
使用 ai-comic-novel-workflow 分析这些素材，先给我原创选题，不要直接写正文。
```

Skill 会先展示完整选题列表。选定题目后，它会先询问大概目标集数和第一集目标时长，再生成故事设定与大纲。第一集可在 1-5 分钟内选择，第 2 集起固定按每集 1 分钟设计。目标集数默认允许上下浮动 10%，且至少允许增减 1 集；例如目标 50 集时，最终应在 45-55 集内，不能只写到 40 集。若剧情确需超出区间，必须先说明原因并取得用户确认。

也可以直接说明创作条件：

```text
根据这些素材创作一部 24 集的都市悬疑漫剧小说。第一集 3 分钟，后面每集 1 分钟；使用第一人称，自动分批，每批 3 集。
```

## 默认工作流

1. 素材与爽点机制分析
2. 5-8 个原创选题
3. 用户确认大概目标集数和第一集时长
4. 故事圣经
5. 核心大纲
6. 强化大纲
7. 内容风险审查
8. 用户确认创作方案
9. 分批创作正文
10. 质量、连续性和语言检查
11. 人物与关键场景确认提示词
12. 最终润色与 Word 稿导出

## 分集质量门

- 不设置固定总字数，以用户确认的大概目标集数、默认允许区间和剧情闭环作为完成标准
- 第一集目标时长由用户确认，必须在 1-5 分钟内；选择“按建议”时默认建议 3 分钟
- 第 2 集起每集目标时长固定为 1 分钟
- 每集必须有观众价值点
- 任意连续 3 集至少有一个明确爽点
- 任意连续 6 集至少有一次强兑现或阶段高潮
- 不允许连续两集只有铺垫
- 第一集开头评分至少 9/10
- 第 2-3 集开头评分至少 8/10
- 后续集数开头评分至少 7/10
- 连续 3 集不得使用同一种开头钩子
- 工作稿的创作标注放在正文之前，最终 Word 稿自动移除

## 校验工具

仓库提供三个脚本：

```text
scripts/count_chinese_characters.py
scripts/validate_chinese_manuscript.py
scripts/validate_episode_payoffs.py
```

它们分别负责正文字符统计、意外英文检查，以及时长/开头钩子/价值点/爽点节奏检查。字符统计用于制作记录和异常检查，不作为总长度门槛。

## 目录说明

- `SKILL.md`：Skill 的轻量入口和核心执行要求
- `agents/interface.yaml`：Codex 显示与运行兼容信息
- `references/`：完整工作流、开头钩子、爽点、内容边界和交付格式
- `scripts/`：确定性校验工具
- `reports/`：Skill 工程与输出风险分析资料

## 不适用范围

本 Skill 不用于：

- 模仿或复刻某部受版权保护作品
- 单段文字的简单润色
- 直接生成图片或视频
- 保证作品一定通过某个平台审核

平台规则会变化，最终发布前仍应根据目标平台的最新要求进行人工检查。
